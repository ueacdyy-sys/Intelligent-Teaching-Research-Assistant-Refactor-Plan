shape, PgBouncer 180 runtime, and mixed read/write workload stack.

## Interpretation

The current P55 mixed shape can pass a single `mixed4400` step under the 3000ms
P99 guardrail with zero errors. This is a material improvement over the earlier
configuration bottleneck.

The limit has not been hit by errors or the 3000ms guardrail yet, but the
dominant bottleneck is already clear: Identity revoke-cycle gateway DB pool
queueing. At `mixed4400`, the revoke phase accumulated about `8.85M ms` of pool
acquire wait.

Do not promote this as full-system ultra-concurrency support:

- one sample is not sustained depth;
- root workflow runtime SLO coverage is not complete;
- real interactive tail latency still needs root workflow evidence;
- the current runner uses module-shaped synthetic workloads, not every product
  workflow from the immutable requirements.

## Next Step

For limit discovery, run one overdrive step (`mixed5800`) with the same P55
shape and the current 3000ms guardrail. For engineering optimization, focus on
reducing Identity revoke-cycle pool queueing before running longer sustained
multi-sample evidence.
