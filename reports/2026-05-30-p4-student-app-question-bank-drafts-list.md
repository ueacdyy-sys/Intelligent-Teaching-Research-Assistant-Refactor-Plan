# P4 Student App Question Bank Drafts List

## Slice

- SDD: `docs/sdd/0065-student-app-question-bank-drafts-list.md`
- Root requirement anchor: Student App includes account login, AI tutor, student archive, teaching materials, personalized question bank, and scan-to-answer.
- Existing refactor evidence: tutoring-analysis results can persist `questionBankDraftRef`, and Student App AI tutor requests already default to the personalized-check intent.

## Contract

- Added `GET /v1/student-app/question-bank-drafts`.
- Requires Agent API key plus Principal Context.
- Requires a Student App principal with `STUDENT_OWN_READ` and own-student access mode.
- Accepts optional `pageSize` and `cursor`.
- Forces the query to the authenticated student's own ID.
- Returns metadata-only personalized question-bank draft entries: tutoring request id, archive item id, source material, result summary/ref, draft ref, and timestamps.

## Design Notes

- This is a Student App contract and conservative bridge to the personalized question-bank surface, not a new storage model.
- Draft content remains behind `questionBankDraftRef`; the endpoint exposes metadata only.
- Teacher desktop, remote social, service, and missing-`STUDENT_OWN_READ` principals are rejected before repository access.
- The query is forced to `SUCCEEDED`, student-owned tutoring results for the authenticated student.
- PostgreSQL reuses `teaching_tutoring_analysis_requests` and adds `question_bank_draft_ref IS NOT NULL`.
- No SQL table, package manifest, OCR/RAG/model, or training dependency was added.
