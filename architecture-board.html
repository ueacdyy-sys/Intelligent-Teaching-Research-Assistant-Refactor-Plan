模块边界与禁止跨界

这页是给 AI 施工用的边界说明。每个模块只做自己该做的事，跨模块只能走 API、事件或端口接口，不能直接互相读库、互相 import、互相偷状态。

可复用 可替换 禁止串线

总规则

UI 调用 BFF，BFF 调用用例，用例调用端口，端口由数据、工具、AI Worker 实现。业务规则不能依赖具体框架、数据库、浏览器、Office、CLI。

复用方式

复用不是复制代码，而是沉到 Shared Kernel、契约 SDK、Domain Event、Tool Manifest。只有稳定、跨模块共用的东西才能下沉。

禁止方式

禁止前端直接拼后端地址，禁止 Agent 直接执行命令，禁止 AI Worker 写主库，禁止一个模块直接改另一个模块的表。

API、命令与事件契约

重构时先写契约，再写实现。UI、Go API、Rust Harness、Python Worker 都按契约通信，避免弱模型时代那种“前端猜字段、后端临时返回”的混乱。

OpenAPI Domain Events WebSocket Command Gate

Query API

只读查询，例如列表、详情、搜索、状态。必须分页、可过滤、错误码稳定，不触发副作用。

Command API

会改变状态的请求，例如创建测验、发布资料、执行工具。必须返回 commandId 或 taskId，可追踪。

Event Stream

长任务、融合回答、训练、工作流执行通过事件流展示进度，UI 不轮询拼状态。

目标技术栈与语言分工

不要用一种语言解决所有问题，也不要为了换语言重写所有问题。Rust 负责本机可信边界，Go 负责真正拥有业务/任务/事件语义的平台服务，TypeScript 负责工作台体验，Python 作为 AI 工作者隔离保留。

TypeScript UI

教师工作台、科研工作台、学生端、审批面板、数据可视化。迁移期可继续 React/Vite；真正减重靠 Tauri 替换 Electron、统一 SDK、减少散乱状态。

BFF、OpenAPI 合约、任务编排、事件处理、队列 worker、认证授权、业务子系统 API。适合长期维护和开源；不建议先做只转发 FastAPI 的空壳代理。

50ms 内的主要消耗不是语言本身，而是教学写入批等待、数据库 insert、响应编码、身份写限流等待，以及对话路径的客户端到服务端差距。继续盲测收益低，应该转入功能重构。

10ms 路线：减少批等待、预编码响应、缩短写事务 真实 AI/RAG/OCR 还未纳入生产10k基线

下一步不再卡性能

性能优化已经完成到“能支撑重构继续前进”的门槛。后续性能工作只在新模块落地时随切片验证，不再长期停留在反复压测。

医疗问题复杂，不能只靠一次 RAG。 不做诊断、药物、疾病编码、临床流程。 把复杂度转译为课堂材料、学生档案、错题、科研知识库、外部工具和工作流的多源协同。 LeadAgentTriage 记录领域数量、风险、证据需求和路由原因。
原子 Skills 支撑上层 Agent。 不复制医学 skill 名称和医学知识库。 建设教育版 skill 家族：当前 8 个示例已覆盖教学检索、练习推荐、科研检索、深度研究、配置检查、压测、工作流草稿、工具调用等方向。 每个 Skill 必须有 manifest、schema、权限、示例、Evidence 字段和禁止行为。
LeadAgent + 专业 Worker Agent。 不把所有能力塞进一个超级聊天 Agent。 LeadAgent 只做分诊、拆解、预算和汇总；Teaching、StudentTutor、Research、Analysis、Workflow、ToolControl、ModelExperiment 分角色执行。 WorkerRoleManifest、Skill 白名单、跨域访问策略和失败降级测试齐全。
SwarmCoordinator 判断单 Agent 还是 Swarm。 不把 Swarm 作为默认问答路径。 低风险只读任务走单 Worker 快速通道；跨教学/科研/学情/工具/性能诊断时才进入 Swarm。 RouteDecision、ConflictResolution、FinalMergePolicy、预算和 P99 进入报告。
Harness Engineering 保障安全边界。 不允许 Agent 直接 shell、写文件、改库、跑插件。 Agent 只提交意图；Rust/Go Harness 执行权限校验、审批、沙箱、Evidence、Rollback。 无 manifest、无审批、无 evidence、不可回滚的高风险动作默认拒绝。
短期记忆、长期记忆和上下文共享。 不把 Mem0 或外部向量库变成默认依赖。 短期记忆进 AgentRun/SharedContext；长期记忆走 Memory Port，按用户、班级、课程、科研库分域。 sourceEvidence、redactionState、retentionPolicy、delete/revoke 行为可测。
VLM、训练、vLLM、量化增强项目含金量。 不为炫技拖垮安装包、虚拟环境和核心路径。 ModelExperimentAgent 只做实验计划、评估和适配器注册；执行交给可选 AI Worker Admission。 datasetScope、资源预算、评估报告、回滚计划、默认关闭状态全部通过。
面试题把项目讲得像真实工程。 不把术语当完成度。 把每次 Agent 动作沉淀为任务轨迹、权限轨迹、证据轨迹和性能轨迹，能面试，也能工程验收。 SDD/TDD、质量门禁、Root SLO、混合读写压测和报告必须一致。

Skills-Agent 两层

底层是可测试、可复用、可限权的原子 Skills；上层是 LeadAgent 和 Worker Agents。Agent 只负责计划、选择和汇总，真正影响文件、网络、系统和业务数据的动作必须交给 Harness 执行。

LeadAgent 分诊

先判断任务属于简单答疑、教学写入、学情风险、科研检索、工具控制、性能诊断还是模型实验；再记录风险、数据范围、是否写入、是否需要 Swarm 和人工确认点。

教育版 ReAct / Agent Loop

每个 AgentRun 都走“观察意图、制定计划、选择 Skill、执行/检索、校验证据、反思降级、输出结论”的闭环；循环次数、token、耗时、风险和证据不足都会触发停止或转人工。

SwarmCoordinator

先判断走单 Agent 快速通道还是多 Agent 协作。路由依据包括领域数量、风险级别、数据敏感度、是否写入工具、证据要求和预算；只有跨教学、科研、知识库、工具或外部应用的复杂任务才进入 Swarm。

Harness 执行链路

Command> LeadAgent> Swarm/Worker> Skill> Policy> Approval> Tool Adapter> Evidence> Rollback

业务模块只提交意图和参数，不能绕过 Harness 直接 shell、browser、office、file write。

权限清单 Manifest

每个 Skill、工具、插件、工作流都必须声明：输入输出 schema、读写范围、是否联网、是否打开外部应用、是否可回滚、需要什么角色、风险级别和预算。

证据与回滚

每次执行保存 request、参数 hash、命令预览、输出摘要、文件 diff、截图/日志、审批记录。可回滚的自动回滚，不可回滚的必须人工审批。

记忆与上下文

短期记忆只属于当前 AgentRun 和 SharedContext；长期记忆必须通过 Memory Port 写入。学生隐私、私密科研资料、外部模型上下文都必须可脱敏、可撤销、可解释来源。

渐进式 Skill 披露

LeadAgent 先只读取 Skill 摘要、成本和风险；选中后才展开 schema、样例和实现提示，避免一次把全量工具说明塞进上下文。

约束与熵管理

每轮 Agent Loop 都检查预算、循环次数、上下文漂移、输出证据和人工确认点；高风险、低置信或无证据结果必须降级。

可借鉴，不照搬

借鉴的是复杂问题拆解、强安全边界、可迁移 Agent 工程；医疗诊断、VLM 训练、Milvus、Mem0、vLLM、SFT/RL 只允许作为未来插件或实验 Worker，不进入基线依赖。

StudentTutorAgent 学生端答疑、错题解释、个性化练习、学习档案反馈专家。 tutor_student、explain_mistake、recommend_practice、read_student_profile。 不能泄露其他学生信息，不能把建议当成绩结论，不能绕过家校/教师策略。 recommend_practice 快路径已要求学生范围、证据、无跨学生数据、无最终评价和 50ms SLO；完整 AI Tutor 仍需后续 async 证据。
ResearchAgent 科研对话、知识检索、节点选择、资料整理专家。 search_knowledge、deep_research、compare_nodes、cite_sources、bookmark_result。 不能把私密资料发给未授权云模型，不能直接生成训练任务。 search_knowledge 快路径已要求来源、知识范围审计和 50ms SLO；deep_research 现在已接入异步受控意图、异步 worker 生命周期、approved retrieval planning、approved retrieval execution 和 approved reasoning/synthesis draft 证据。
AnalysisAgent 学情分析、系统诊断、性能归因、配置检查、故障复盘专家。 analyze_learning_trace、inspect_config、run_benchmark、analyze_trace、propose_remediation。 不能把学情分析当最终评价，不能在没有回滚和审批时修改生产配置。 学习建议和优化建议都必须绑定证据，不允许用空接口推导整系统性能。
WorkflowAgent 工作流生成、插件缺口分析、自动测试和发布草稿。 draft_workflow、generate_plugin_manifest、run_sandbox_test、collect_feedback。 不能直接启用生成代码，不能安装未签名依赖。 发布前必须通过 manifest、沙箱、权限 diff、人工确认。
ToolControlAgent 文件、CLI、浏览器、Office、外部应用控制的执行代理。 run_cli、read_file、write_file、browser_action、external_app_action。 不能自行扩大权限，不能绕过 Harness 审批。 所有执行都有 Evidence 和 Rollback；高风险默认拒绝。
ModelExperimentAgent 可选的模型实验、OCR/多模态、训练任务编排和推理部署评估专家。 draft_model_job、evaluate_model_result、profile_inference、register_model_adapter。 不能作为默认运行时依赖，不能接触未脱敏学生数据，不能绕过资源隔离。 默认关闭；必须有 AI Worker Admission、资源账单、评估报告和回滚方案。

create_quiz TeachingAgent 根据教学目标、题型、难度和知识点生成测验草稿。 objectiveRef、rubricVersion、difficulty、teacherReviewId。 不直接发布给学生，不绕过教师复核。
grade_answer TeachingAgent 按评分规则生成批改建议、错因摘要和复核队列。 submissionId、rubricRef、modelOutputHash、reviewState。 不直接写最终成绩，不隐藏低置信结果。
assess_learning_risk TeachingAgent / StudentTutorAgent / AnalysisAgent 根据测验、点名、作业、辅导记录给出学习风险提示。 profileEventRefs、ruleVersion、confidence。 不替代教师评价，不自动改成绩。
analyze_learning_gap StudentTutorAgent / AnalysisAgent 把错题、缺勤、作业和课堂互动拆成知识点缺口与可行动建议。 eventRefs、knowledgePointIds、evidenceScore、suggestedActions。 不把相关性当因果，不给不可解释标签。
recommend_practice StudentTutorAgent 为学生选择练习、复习资料和下一步学习任务。 studentScope、materialRefs、reason、expiresAt。 不跨学生比较，不推荐无权限资料。
search_knowledge ResearchAgent 检索公开/私密知识库、科研节点回答和引用来源。 docId、chunkId、citation、knowledgeScope。 不把私密库内容发送给未授权节点。
cite_sources ResearchAgent 把回答、教案或科研摘要绑定到可追溯来源和引用范围。 citationIds、quoteScope、sourceHash、retrievalQuery。 不伪造引用，不把未检索内容标成来源事实。
deep_research ResearchAgent 把复杂科研问题拆成检索、对比、引用、汇总和待验证假设。 planSteps、selectedNodes、citations、openQuestions。 不把未验证结论标成事实。
inspect_config AnalysisAgent 读取运行配置、连接池、队列、worker 和缓存设置，形成瓶颈假设。 configRefs、diffHash、riskLevel、hypothesis。 不在无审批时修改生产配置。
run_benchmark AnalysisAgent 按计划执行读、写、混合读写、多 worker 和持续压测。 profile、RPS、P95/P99、errorRate、dockerCleanupState。 不拿空接口或单模块数据冒充整系统能力。
draft_workflow WorkflowAgent 把用户描述转换成工作流草稿、权限声明和测试用例。 manifestDiff、sandboxResult、testReport。 不直接发布或启用生成代码。
evaluate_model_result ModelExperimentAgent 评估可选 OCR、多模态、推理或训练实验产物是否值得接入。 datasetScope、metricReport、resourceCost、adapterRisk。 不把实验依赖变成默认安装项。
run_tool ToolControlAgent 通过 Harness 调用 CLI、文件、浏览器、Office 或外部应用适配器。 approvalId、toolRunId、logs、rollbackRef。 不绕过 Harness，不扩大权限。
路由场景 触发条件 执行模式 降级策略 验收指标
简单教学问答 单领域、只读、低风险、上下文足够。 单 Worker Agent 快速通道。 检索失败则返回可解释缺口，不启动 Swarm。 P95、token、引用命中率、错误率。
复杂学情求助 同时出现错题、缺勤、作业异常、情绪化表达或长期低置信记录。 LeadAgent + StudentTutorAgent + AnalysisAgent；必要时 TeachingAgent 复核。 高风险只给支持性建议和教师复核摘要，不自动贴标签或下结论。 风险依据、知识点缺口、建议置信度、人工复核点。
跨教学与科研任务 同时涉及学生档案、知识库、节点融合或资料生成。 LeadAgent + SwarmCoordinator + 多 Worker Agent。 冲突结果进入人工确认，敏感数据只读降级。 路由理由、SharedContext 裁剪、冲突处理证据。
工具和外部应用控制 需要文件写入、命令、浏览器、Office、插件或远程入口。 ToolControlAgent 只提交意图，Harness 执行。 无审批、无 rollback、无 manifest 时拒绝。 审批链、Evidence、Rollback、权限 diff。
性能与配置优化 用户要求评估并发、读写瓶颈、Docker 多 worker 或系统极限。 AnalysisAgent 生成诊断计划，Benchmark Skill 产证据。 压测证据不足时只给假设，不给“支持超高并发”结论。 真实混合读写 RPS、P99、错误率、Root SLO 决策。
多模态或模型实验 需要 OCR、多模态批改、训练、量化、推理部署或外部模型评估。 ModelExperimentAgent 只生成实验计划，AI Worker Admission 决定是否允许执行。 默认关闭；无脱敏、无资源预算、无评估报告时不接入主系统或默认安装包。 实验指标、资源成本、数据范围、适配器风险、回滚方案。

A0 契约骨架 先固化 AgentTask、WorkerRoleManifest、SkillManifest、SharedContext、Evidence、GuardrailResult。 让后续任何语言和模型都按同一套边界通信，避免 AI 临时造字段。 契约 schema、示例、结构校验、回滚说明。 未定义契约就写 Agent 运行时代码。

仓库历史中的 .env、证书私钥、固定口令、测试密钥必须清理并轮换。 危险能力默认关闭：命令执行、文件写入、Office 自动化、外部应用控制、远程控制。 测试不能依赖真实外网、真实第三方账号、真实浏览器状态。 README 不能宣称未完成能力已经生产可用。

开源版本能力边界

Community：教学/科研基础工作台、本地知识库、基础多模型对话、手动节点管理。 Local Advanced：Agent Harness、本机 CLI/API 适配、工作流池、插件池，但默认审批。 Pro/Private：社交平台接入、远程控制、训练集管理、多设备协同、企业审计。 所有版本都保留契约测试、权限声明、审计证据。
治理项 检查方法 通过标准 失败后动作
Secret Scan gitleaks/trufflehog + 人工检查配置目录。 当前文件和 Git 历史均无真实密钥/私钥。 清历史、轮换密钥、重建证书。
License Scan 扫描 npm/pip/cargo/go 依赖许可证。 无冲突许可证，NOTICE 完整。 替换依赖或隔离为可选插件。
Contract Test OpenAPI 生成 mock server，前后端 SDK 跑契约测试。 字段、错误、分页、鉴权全部稳定。 先修合约，不继续写 UI。
Harness Policy Test 模拟读写文件、命令、浏览器、外部应用。 默认拒绝危险操作，可审批，可审计，可回滚。 阻断 Agent 能力发布。
CI Quality Gate lint、typecheck、unit、contract、e2e、security、build。 主分支全绿，E2E 不依赖外网。 冻结合并，先修测试环境。
Feature Truth 功能清单对照 UI 和 API。 已完成、实验、禁用、规划四种状态清楚。 README 和界面降级说明。
专业判断：这个项目开源的第一目标不是“功能震撼”，而是“边界可信”。只要边界可信，即使功能少一点，也会像一个认真项目；如果边界不可信，功能越多风险越大。
