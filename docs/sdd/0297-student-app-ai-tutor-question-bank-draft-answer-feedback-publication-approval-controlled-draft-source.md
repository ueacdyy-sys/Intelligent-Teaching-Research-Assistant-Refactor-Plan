# SDD 0297 - Student App AI Tutor Question-Bank Draft Answer Feedback Publication Approval Controlled Draft Source

## Problem

SDD 0296 makes the reviewed learner feedback artifact traceable to a controlled
feedback draft generated by `StudentTutorAgent.generate_question_bank_answer_feedback`.
The next product gap is to move publication approval onto that stronger source
chain. Publication approval should no longer rely only on the legacy 0272
reviewed artifact path when a controlled-draft-sourced artifact is available.

The immutable root requirements require the Student App tutoring flow to remain
useful while protecting student data, answer keys, worker state, model output,
and unsafe automated publication. This slice advances the feedback loop while
keeping student-visible delivery and durable archive persistence as separate
reviewed steps.

## Scope

Add an auditable publication approval runtime for the Student App question-bank
answer feedback chain that consumes 0296 controlled-draft-sourced reviewed
feedback artifact evidence.

The runtime consumes:

- the READY 0296 reviewed feedback artifact controlled draft source report;
- the reviewed learner feedback artifact and its source controlled draft ref;
- a human TEACHER or ADMIN publication approver;
- a policy that allows only approval evidence and still blocks delivery,
  persistence, model inference, HTTP, tools, devices, and Swarm.

The runtime records
`STUDENT_APP_AI_TUTOR_QUESTION_BANK_DRAFT_ANSWER_FEEDBACK_PUBLICATION_APPROVED_FROM_CONTROLLED_DRAFT_SOURCE_FOR_STUDENT_VISIBLE_DELIVERY_NOT_PERSISTED`.

This slice intentionally does not create a student-visible delivery envelope,
publish feedback, write a database row, persist to the student archive, add an
OpenAPI path, execute HTTP, call a model, remote-control devices, mutate local
tools, or enable Swarm.

## Acceptance Criteria

- The runtime requires a human TEACHER or ADMIN approver.
- The runtime requires READY 0296 source evidence.
- The reviewed feedback artifact must prove `reviewedFromControlledDraft`.
- The approval must match source controlled draft artifactId, artifactId,
  submissionId, requestId, questionBankDraftRef, tutoringAnalysisRequestId, and
  archiveItemId from the 0296 artifact.
- The approval must prove controlled draft source verification, learner
  feedback review, age appropriateness, own-student scope, answer-key blocking,
  worker metadata blocking, raw model output blocking, result-ref blocking,
  internal error blocking, and future delivery runtime requirement.
- The runtime is idempotent by idempotency key and rejects conflicting replay.
- The runtime rejects answer text, answer keys, expected answers, explanations,
  result refs, worker/claim fields, raw model output, student delivery fields,
  internal error messages, and unsafe HTML-like text.
- The audit proves package scripts, strict quality, root workflow coverage,
  structure verification, SDD, and architecture board track 0297.

## Performance

This is a control-plane approval step and does not change the production hot
path. It is held to the Student App control-plane target of P99 <= 50ms. Current
whole-system evidence remains `22,435.1 read/write RPS`, `P99 44.44ms`,
`0 errors`; no new `production10k` run is required for this slice.

## Rollback

Remove the 0297 runtime, runtime tests, audit, audit tests, report, package
script, strict quality hook, root workflow coverage hook, structure verifier
entries, SDD, and architecture-board 10.37 text. Keep 0293-0296 and legacy 0273
intact because feedback draft generation, source review, and legacy approval
remain valid independent slices until downstream delivery consumes 0297.
